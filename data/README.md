# CineMind AI Datasets

This directory contains raw and processed data used by CineMind AI for hybrid recommendations, sentiment analysis, and Explainable AI.

## Sources and Licenses

1. **MovieLens Latest Small Dataset**
   - **Source:** GroupLens Research, University of Minnesota
   - **URL:** https://grouplens.org/datasets/movielens/latest/
   - **Citation:** F. Maxwell Harper and Joseph A. Konstan. 2015. The MovieLens Datasets: History and Context. ACM Transactions on Interactive Intelligent Systems (TiiS) 5, 4: 19:1–19:19. https://doi.org/10.1145/2827872
   - **License:** Non-commercial educational and research use.
   - **Files:** `movies.csv`, `ratings.csv`, `tags.csv`, `links.csv`.

2. **Stanford Large Movie Review Dataset (IMDb) / Rotten Tomatoes Reviews**
   - **Source:** Andrew L. Maas, Raymond E. Daly, Peter T. Pham, Dan Huang, Andrew Y. Ng, and Christopher Potts. (2011). Learning Word Vectors for Sentiment Analysis. The 49th Annual Meeting of the Association for Computational Linguistics (ACL 2011).
   - **License:** Open for academic and research purposes.
   - **Usage:** Written reviews with real audience/critic text for sentiment classification and movie-level aggregation.

## Directory Structure
- `data/raw/`: Original downloaded CSV files.
- `data/processed/`: PySpark-cleaned datasets, movie-level statistics, sentiment aggregates, and vector embeddings.
- `data/processed/evaluation_report.json`: Metrics (Precision@K, Recall@K, NDCG@K, RMSE, MAE) generated by `scripts/evaluate_models.py`.
